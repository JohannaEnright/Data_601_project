This project uses a dataset containing predictors of heart disease and patient diagnoses from Kaggle: https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction. 
A logistic regression is used to model and predict patient heart disease outcomes. 
I go into further investigation on sex as one of the key predictors of heart disease and differences in significant heart disease predictors between sexes.
All of this can be found in the heart_disease_prediction.ipynb script.
The images are also used to enhance the heart_disease_prediction.ipynb script, and the original downloadable dataset is provided in the heart_disease.csv file.
